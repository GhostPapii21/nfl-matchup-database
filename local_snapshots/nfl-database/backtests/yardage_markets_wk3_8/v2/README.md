# Stage A, offline v2

Run `python3 backtests/yardage_markets_wk3_8/v2/build.py` from the repository. Stage B only: `python3 backtests/yardage_markets_wk3_8/v2/grade.py`. Stage A never invokes grade.py. Existing v1 artifacts remain untouched.

Sources: every JSON in the original builder's saved source roots (both replay raw directories, runs, week8, week9), plus ../raw. Only timestamp-verified pre-kickoff main yardage markets qualify. Exact bookmaker/player/market/side duplicates use the latest pre-kickoff snapshot, with source-path tie breaking. Coverage counts these admitted quotes, distinct events and distinct books. Alternate market keys never enter candidates. Market outcomes lacking a price or carrying zero American odds are excluded.

Consensus: one player-market-side-week; median main line across admitted books, then median American price among books quoting that exact line. An unquoted median midpoint retains a missing price and abstains. Players use normalized names with nine explicit suffix/nickname aliases documented in build.py; aliases are identity metadata only. Candidates are book quotes; legs are the training/selection unit. Quote snapshots can differ; this is a retrospective consensus of saved pre-kick quotes, not a synchronized executable book offering. Each consensus leg uses features from its earliest constituent quote, conservatively restricting saved game-odds snapshots to that time. Spread and total are latest per-book quotes then medians; absent odds stay missing.

All PBP features use weeks strictly before the leg's week. Team identity comes from the player's latest prior participation among the scheduled teams; unidentified newcomers abstain. Prior yard average includes zero-yard team games without recorded carries/targets; this is not an active-game-only average. Shares use team carries and named targets; opponent allowance is team yards/game, not position-adjusted. Final corrected PBP and current player-name metadata are saved-data limitations. Train settlement uses zero yards for a matched player without recorded carries/targets, so participation void rules cannot be reconstructed. Oct27 Sharp is HINDSIGHT only and never a fitting feature. Missing HINDSIGHT rates abstain under Sharp ON.

Train reports cover weeks 3–6 only. Holdout rows have result=withheld and blank actual, P/L and stake. No holdout grading/report exists in Stage A. Rule search and trait splits are exploratory and potentially overfit; no holdout performance claims are made. See RULES.md and slip_method.md for frozen decisions.
