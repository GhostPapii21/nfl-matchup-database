## Method (Superpowers systematic-debugging)
1. Reproduce: read the PFF value in Rico's signed-in session (read-only, no scraping) and screenshot it to pff_raw/ with the time.
2. Compare it with an independent reference: Open-Meteo archive + NWS station obs (weather); ESPN win rates + our nflverse play-by-play (line play); ESPN box score + our ESPN play log (stats; note both come from ESPN, so NGS/PFR are needed for true independence); ESPN injuries API (status).
3. Classify each gap: stale/not updated · wrong game mapping · wrong player mapping · methodology difference (not a bug) · unknown. Only name a root cause when evidence proves it (for example, PFF weather matches Atlanta coords → wrong venue mapping). Otherwise mark it unknown.
4. Rico's cross-check rule: no PFF input counts unless a second public source agrees. If they disagree, the leg gets a caution flag.
