# Mandatory NFL projection preflight

## Order and acceptance
Before every NFL projection, matchup or prop analysis: (1) source inventory and retrieval audit, (2) load and run betting-game-brainstorm, (3) load and run all15 phases of nfl-game-script-run with nfl-betting-script and football-period-game-flow where applicable, (4) validate implementation/data/model/market evidence, (5) independent final vet. This skill establishes workflow; it does not claim programmatic enforcement is installed or tests passed.

## Source inventory and pulls
Build a per-run source manifest. Record source name, URL/API or local artifact, purpose, season, data-through week/time, pull time, exact fields retrieved, access result, sample size, provenance, fallback attempted, and artifact hash where supported. Statuses: SUCCESS, SAVED_ONLY, MISSING, LOGIN_REQUIRED, STALE, ERROR, NOT_APPLICABLE with reason. Discover live connectors before assuming lack of access. Read existing evidence and approved access notes; attempt authorized fallbacks and public-method research before escalating. Do not purchase subscriptions/data or bypass access controls.

Source registry categories to inspect and retrieve applicable evidence:
- Core: ESPN NFL box/play-by-play/depth/injury/logs; nflverse datasets and releases (pbp, rosters, schedules, snaps, participation where actually published); PFR logs/advanced defense; official NFL gamebooks.
- Scheme/coverage: saved FTN charting, PFR per-defender, PFF approved matchup/grade sources with second dated source, Sharp Football Analysis with corroboration, StatRankings, PropsMadness Pro, SumerSports; Fantasy Points crosscheck only. Listed source is not verified access or verified availability of every field.
- Tracking/visuals: public Next Gen Stats tables/charts, NFL Pro only with established authorized access, official NFL/ESPN/team highlights and gamebooks. Selected targeted-route charts do not prove full route trees, routes run, participation or assignments.
- Availability: official NFL/team injury/inactive/trade reports and official posts; ESPN crosscheck, Ourlads dated depth context, AP and RotoWire reporting. Practice status, designation, active status and workload differ.
- Weather: NWS stadium grid/hourly API and Open-Meteo through established weather runner; official venue roof status. Rain probability is not intensity or a fitted adjustment.
- Markets: FanDuel price of record; DraftKings/Pinnacle comparison, Odds API via canonical credit-accounted puller, read-only Outlier, PrizePicks and optional Polymarket. Match event/stat/player/period/line/side/time, preserve quote provenance. Missing exact quote=NOLINE, never zero. No new spend without authority.
- Local: main NFL database authority files, phase script, team profiles, dated usage/injury/replacement research, per-run checklists/reports/manifests/odds, postmortems/backtests, model source/revisions, frozen inputs/output and test artifacts. Validate file contents; stub or corrupt dataset is not usable evidence.

## Brainstorm then15phases
Load current skill bodies, not remembered summaries. Scenario read precedes projections. Include possession, QB versus pressure, target competition, route/defender mapping, injuries/replacements, miss causes present or absent this week, alternate scripts and pre-mortem. Infer no fixed defender from a tackler, no pressure from blitz alone, no personnel package from aggregate snaps and no automatic transfer of another player's targets.

All15 phases: data reconcile; opportunity; defensive profiles; defender coverage; pressure/blitz/checkdowns; QB card; roles/RB rules; injuries; NGS; film; environment; source audit; game script; models/price/edge; inactives refresh. Output required checklist and report artifacts. Reconcile embedded old rule text against latest dated user approvals rather than blindly copying superseded restrictions. Passing yards remain off slips under the owner's current rule; research modeling does not grant betting permission.

## Validation and autonomous repairs
On fixable failures, log issue, brainstorm, implement through authorized coding tools, stress-test, add regression tests and independent AI/Superpowers-equivalent review, then rerun. Preserve input cutoffs/seeds/revisions; separate frozen forecasts, hindsight diagnostic reconstructions, raw scenario estimates and market-anchored estimates. Never claim calibration from matching a single observed game or test-pass counts. Missing inputs must not become invented rates. Track meaningful steps, revisions, commands, measured improvement/regression, remaining problems and review evidence in the designated project tracker. No intermediate access complaints or routine proceed questions; escalate only genuinely exhausted blockers, without claiming completion. Final vet requires verified source/preflight, brainstorm, phases, integration tests, independent reviews and market checks.
