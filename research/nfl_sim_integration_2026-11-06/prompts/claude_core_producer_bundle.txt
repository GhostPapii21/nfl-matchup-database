## Input interface

`spec` includes canonical `game`, information `cutoff_utc`, `frozen_at_utc`, `generated_at_utc`, `mode`, `config_id`, and optional `trial_start` and `max_steps`. Each `inputs` entry has a logical input ID, relative path, source, selected record IDs, schema version, usage, source event/publication/retrieval UTC clocks and an as-of evidence reference. Retrieval after cutoff requires `asof_verified: true` and evidence. This validates supplied evidence declarations; it cannot authenticate an arbitrary source's assertion. Real-data source certification is a handoff blocker.

The registry retains authoritative, namespaced strings and crosswalk evidence, including zero padding. It includes canonical game metadata, the versioned team alias map, player roster records and entity-scoped crosswalk rows. Null player identities require `identity_status: UNRESOLVED`; they feed unassigned buckets, never named projections.

The model contains explicit version/provenance/sample-size metadata and market lineage, joint trial role states (availability, depth-chart state, rotation weights and intended target-depth distributions), a shared environment distribution, pre-snap usage cells, catch distributions, outcome cells and try-point distributions. Every distribution is a list of `{value, weight}` rows. Cells are evaluated in supplied order and have explicit IDs; `when` keys compare the shared state using exact matches or `_min`/`_max` bounds. There is no silent league/player/role fallback. If all eligible identities are unavailable, allocation is unassigned. Referenced role weights and distributions remain in the decision trace.

The supported terminal categories are targeted and non-dropback targeted passes, throwaways, spikes, other untargeted attempts, sacks, scrambles, aborted dropbacks without attempts, designed rushes, kneels, credited aborted rushes, no-play, punts, field goals, and explicit period-end runoff. Direct-snap/end-around/QB rush design is an orthogonal label; non-QB throws use the supplied passer identity. Unsupported penalty, untimed-down and defensive-return effects reject execution. Punt/FG/try credits are identified as separate stat ledgers. No betting or settlement profile is defined here.

Per snap: sample usage/terminal category and eligible identities; **increment TARGETS/CARRIES and attempt counts**; draw catch/interception; draw conditional yards/field advancement; apply state changes. The tests intercept the actual outcome call and verify that opportunity counters already exist. Stages retain model/version/source references, sample-size evidence and MODELED flags. Intended depth and depth-chart uncertainty are separate from missing charted routes/personnel/coverage.

Counts and stat yards use exact integers. Ordinary modeled gains stop at the goal line, recorded in the yard trace. Explicit lateral/provider/fumble differences retain separate field advancement, signed adjustments, explanations and event references; failed conservation marks INVALID without redistribution. Unknown identities retain visible unassigned counts and yards and conservatively block the trial's adapter projection.

## Output and replay

One JSONL row is one joint game draw. No marginal resampling or period-engine merge occurs. Every trial includes the full contract object set, ledger-derived primitive/aggregate team and player rows (including rostered known zeros), all terminal counts/residuals, scores, possessions, stages and missing-feature records. Coverage stays UNKNOWN; routes and personnel 11/12/13 stay MISSING, with null values and effects disabled on every event. The TNF audit is referenced only as contract evidence, not loaded into predictive inputs.

Q1–Q4 clocks use 900 seconds each; possession persists over Q1/Q2 and Q3/Q4, with explicit halftime receiving transition. Costs are capped at the current period, with no clock debt. Explicit runoff is supported as a separate transition event. Linked tries stay in the snap's period at 0:00. The only supported OT profile is the existing **single_possession_approx_declared_limitation**, frozen with its duration/termination/entitlement limitations. Consumers requiring official OT must block this profile. Unplayed OT is known zero; cap-limited future/unfinished aggregates are null/INCOMPLETE, never invented zeros.

Canonical UTF-8 JSON uses sorted keys, compact separators, `ensure_ascii=False`, and rejects nonfinite numbers (`python-json-sorted-compact-utf8-v1`). Wire count/yard values are integers; finite model weights may be fractional. Input manifests sort by logical ID and hash exact file bytes. Run hashes include model settings, cutoff, mode, seed policy, trial range, full commit and dirty/source hashes, dependency/RNG versions and profiles. Creation clocks are excluded from forecast identity and recorded separately. Changed input bytes/cutoff/mode create a new identity. Quote snapshots never enter independent forecasts.

Trial seeds follow contract §2.3 with derivation label `sha256-first-eight-big-endian-v1`, lossless decimal strings and PCG64/NumPy version. Trial order/retries cannot change draws. Batch extension changes the forecast ID while preserving overlapping trial seeds/draws. Code and dependency mismatches or mutation of prepared input bytes block execution.

`output_root/<forecast_digest>/` retains `run_spec.json`, `input_manifest.json`, exact input bytes, exact source snapshot and hash manifest, `trials.jsonl`, and `forecast_ledger.json`. Existing bytes are immutable: differing retry output raises a conflict. The writer checks the exact ordered trial population and recomputes validation, never trusting a caller-supplied PASS. The ledger records input/split/artifact hashes, trial IDs and separate empty result-evidence IDs. New information revisions have new identities. The writer stores invalid/incomplete trials, exposes their counts and explicit exclusions, and never silently conditions the population.

Independent data_only/script_adjusted reject market inputs, market-tainted lineage and postgame evidence. Scenario-only models remain explicitly flagged and block actionable projection. Game-level splits apply to every period/player/trial row through the forecast freeze; no trials are independent evaluation examples.

"""Opportunity-first local CORE producer for nfl-sim-core-contract-v1.

Opt-in frozen model tables, never inferred from historical yard-row assignments.
This is a structural research model, not a fitted forecast or official OT engine.
"""
from __future__ import annotations

from copy import deepcopy
from pathlib import Path

import numpy as np

from joint_inputs import (CONTRACT_VERSION, canonical, digest, freeze_run, integer, safe_path, trial_seed, verify_frozen)
from joint_accounting import (PLAYER_STATS, TEAM_STATS, TARGETED, UNTARGETED, RUSHES, TERMINALS,
                              allocate, derive_tables, finalize_validation, zeros)

OT_PROFILE = {"id": "single_possession_approx_declared_limitation", "period_length_seconds": 600,
              "possession_entitlement": "NOT_OFFICIAL; no guaranteed matching possession",
              "termination": "first score or expiration", "tie_behavior": "tie at expiration",
              "applicability": "research_approximation_only", "limitations": ["NOT_VERIFIED_OFFICIAL_OT"]}
STAT_PROFILE = {"id": "core_integer_offense_v1", "yard_unit": "integer_yards",
                "kneels": "rushing_attempt", "scrambles": "dropback_and_rushing_attempt",
                "sack_loss": "nonnegative_magnitude", "no_play": "no_official_offense_credits",
                "turnovers": "interceptions_plus_lost_fumbles_plus_turnover_on_downs_excluding_punts_and_missed_fg",
                "provider": "MODELED_CONTRACT_PROFILE_NOT_PROVIDER_SETTLEMENT"}


def missing_features():
    return {name: {"status": "UNKNOWN" if name == "coverage" else "MISSING", "value": None,
                   "allows_sim_effect": False, "evidence_scope": "UNAVAILABLE_NOT_ZERO",
                   "source_refs": [], "asof_refs": []}
            for name in ("coverage", "routes", "personnel_11", "personnel_12", "personnel_13")}


def choose(rng, distribution):
    if not distribution:
        raise ValueError("empty distribution: UNSUPPORTED")
    weights = np.array([row["weight"] for row in distribution], dtype=float)
    if not np.all(np.isfinite(weights)) or np.any(weights < 0) or weights.sum() <= 0:
        raise ValueError("invalid distribution weights")
    return deepcopy(distribution[int(rng.choice(len(distribution), p=weights / weights.sum()))]["value"])


def provenance(model, stage, **fields):
    return {"generation_stage": stage, "provenance_refs": model["provenance_refs"],
            "model_version": model["model_version"], "sample_size": model["sample_size"],
            "sample_size_reason": model.get("sample_size_reason"),
            "flags": ["MODELED", *model.get("flags", [])], **fields}


def matches(when, context):
    for key, value in when.items():
        if key.endswith("_min"):
            if context[key[:-4]] < value:
                return False
        elif key.endswith("_max"):
            if context[key[:-4]] > value:
                return False
        elif context[key] != value:
            return False
    return True


class OpportunityModel:
    def __init__(self, frozen, rng):
        self.model = frozen["loaded"]["model"]
        self.rng = rng
        self.roster = frozen["loaded"]["registry"]["players"]
        self.by_ref = {r["record_id"]: r for r in self.roster}
        if len(self.by_ref) != len(self.roster):
            raise ValueError("duplicate roster record ID")
        model = self.model
        if model["ot_rule_profile"] != OT_PROFILE or model["stat_credit_profile"] != STAT_PROFILE:
            raise ValueError("UNSUPPORTED OT/stat profile; consumer must check approximation")
        if not model["provenance_refs"] or not model["model_version"]:
            raise ValueError("decision provenance/model version required")
        if model["sample_size"] is None and not model.get("sample_size_reason"):
            raise ValueError("missing sample size requires a reason")
        self.environment = choose(rng, model["environments"])
        self.roles = {team: choose(rng, rows) for team, rows in model["role_states"].items()}
        self.live_team = {}
        self.live_player = {}
        for team, state in self.roles.items():
            for ref in state["available"]:
                if ref not in self.by_ref or self.by_ref[ref]["team_id"] != team:
                    raise ValueError("availability contains foreign/unknown roster reference")
            # No silent uniform role fallback, depth/rotation/charted features are distinct.
            for role in ("passer", "target", "carry"):
                if role not in state["rotation_weights"]:
                    raise ValueError("availability/depth/rotation distribution MISSING")
            if "depth_chart_state" not in state or not state["target_depth_distribution"]:
                raise ValueError("depth-chart/target-depth uncertainty MISSING")

    def context(self, state):
        return {**state, "score_margin": state["score"][state["possession"]] - state["score"][self.other(state)],
                "team_id": state["possession"], "environment_id": self.environment["environment_id"],
                "role_state_id": self.roles[state["possession"]]["state_id"]}

    @staticmethod
    def other(state):
        return next(t for t in state["score"] if t != state["possession"])

    def identity(self, ref):
        if ref is None:
            return None
        row = self.by_ref[ref]
        if row["player_id"] is None:
            return None
        return {"player_id_namespace": row["player_id_namespace"], "player_id": row["player_id"]}

    def role(self, team, role, modifiers):
        state = self.roles[team]
        candidates = []
        for ref, weight in state["rotation_weights"][role].items():
            if ref == "UNASSIGNED":
                candidates.append({"value": None, "weight": weight})
            elif ref in state["available"]:
                if self.by_ref[ref]["team_id"] != team:
                    raise ValueError("foreign role player")
                candidates.append({"value": ref, "weight": weight * modifiers.get(role, {}).get(ref, 1)})
        if not candidates:
            # Explicit unassigned bucket, never an invented named player.
            return None
        return choose(self.rng, candidates)

    def opportunity(self, state):
        context = self.context(state)
        cell = next((c for c in self.model["usage_cells"] if matches(c["when"], context)), None)
        if cell is None:
            raise ValueError("UNSUPPORTED pre-snap state; no silent fallback")
        terminal = choose(self.rng, cell["terminals"])
        if terminal not in TERMINALS:
            raise ValueError(f"UNSUPPORTED terminal {terminal}")
        team = state["possession"]
        modifiers = cell.get("role_weight_multipliers", {})
        passer = self.role(team, "passer", modifiers) if terminal in TARGETED | UNTARGETED | {"sack", "scramble", "aborted_dropback_no_attempt"} else None
        receiver = self.role(team, "target", modifiers) if terminal in TARGETED else None
        runner = passer if terminal == "scramble" else self.role(team, "carry", modifiers) if terminal in RUSHES else None
        assignments = {"passer": self.identity(passer), "receiver": self.identity(receiver), "runner": self.identity(runner)}
        depth = choose(self.rng, self.roles[team]["target_depth_distribution"]) if terminal in TARGETED else None
        t, p, credit = allocate(terminal, team, **assignments)
        trace = [provenance(self.model, "PRE_SNAP", context=context, usage_cell_id=cell["cell_id"],
                            role_state=self.roles[team], conditional_role_weights=modifiers, target_depth=depth),
                 provenance(self.model, "OPPORTUNITY", team_counts=deepcopy(t), player_counts=deepcopy(list(p.values())))]
        # These increments occur in the execution path before outcome() can draw anything.
        live = self.live_team.setdefault(team, zeros(TEAM_STATS))
        for k in TEAM_STATS:
            live[k] += t[k]
        for key, row in p.items():
            bucket = self.live_player.setdefault((team, *key), zeros(PLAYER_STATS))
            for k in PLAYER_STATS:
                bucket[k] += row["stats"][k]
        return {"terminal": terminal, "team": team, "team_credits": t, "players": p, "credit": credit,
                "assignments": assignments, "trace": trace,
                "context": {**context, "terminal": terminal, "target_depth": depth,
                            "passer_ref": passer, "receiver_ref": receiver, "runner_ref": runner}}

    def outcome(self, opportunity):
        terminal = opportunity["terminal"]
        catch = choose(self.rng, self.model["catch_distributions"][terminal]) if terminal in TARGETED else "NA"
        if catch not in {"COMPLETE", "INCOMPLETE", "INTERCEPTION", "NA"} or terminal in TARGETED and catch == "NA":
            raise ValueError("unsupported catch outcome")
        opportunity["trace"].append(provenance(self.model, "CATCH", outcome=catch))
        context = {**opportunity["context"], "catch": catch}
        cell = next((c for c in self.model["outcome_cells"] if matches(c["when"], context)), None)
        if cell is None:
            raise ValueError("UNSUPPORTED outcome state")
        outcome = choose(self.rng, cell["distribution"])
        for key in ("yards", "elapsed_seconds"):
            integer(outcome[key], key, 0 if key == "elapsed_seconds" else None)
        if catch in {"INCOMPLETE", "INTERCEPTION"} or terminal in UNTARGETED | {"no_play", "aborted_dropback_no_attempt", "punt", "field_goal", "period_end_runoff"}:
            if outcome["yards"] != 0:
                raise ValueError("non-yard-bearing outcome must have zero offense yards")
        if terminal == "sack" and outcome["yards"] > 0:
            raise ValueError("sack cannot have positive yards")
        opportunity["trace"].append(provenance(self.model, "YARDS", outcome_cell_id=cell["cell_id"],
                                               raw_outcome=deepcopy(outcome)))
        return catch, outcome


def derive_possessions(events):
    possessions = {}
    for e in events:
        pid = e["possession_id"]
        p = possessions.setdefault(pid, {"possession_id": pid, "team_id": e["pre_state"]["possession"],
                                        "start_event_id": e["event_id"], "end_event_id": None,
                                        "end_cause": None, "period_segments": [], "clock_seconds": 0,
                                        "field_advance_yards": 0, "points": 0, "turnovers": 0,
                                        "definitions": {"points": "possession_team_credited_points_only",
                                                        "field_advance_yards": "offensive_advancement_excluding_special_teams"}})
        if p["end_cause"] is not None:
            raise ValueError("possession continues after termination")
        if not p["period_segments"] or p["period_segments"][-1]["period_id"] != e["period_id"]:
            p["period_segments"].append({"period_id": e["period_id"], "clock_seconds": 0})
        p["period_segments"][-1]["clock_seconds"] += e["elapsed_clock_seconds"]
        p["clock_seconds"] += e["elapsed_clock_seconds"]
        t = e["team_credits"].get(p["team_id"], zeros(TEAM_STATS))
        p["field_advance_yards"] += t["field_advance_yards"]
        p["points"] += t["points"]
        p["turnovers"] += t["turnovers"]
        p["end_event_id"] = e["event_id"]
        if e.get("possession_end_cause"):
            p["end_cause"] = e["possession_end_cause"]
    return list(possessions.values())


def simulate_trial(frozen, index, *, model_class=OpportunityModel):
    verify_frozen(frozen)
    if index not in frozen["run_spec"]["trial_indices"]:
        raise ValueError("trial_index not assigned in frozen run specification")
    run = frozen["run_spec"]
    spec = frozen["spec"]
    game = spec["game"]
    seed = trial_seed(frozen, index)
    model = model_class(frozen, np.random.Generator(np.random.PCG64(int(seed))))
    trial_id = f"{frozen['forecast_id']}/trial/{index}"
    features = missing_features()
    teams = [game["home_team_id"], game["away_team_id"]]
    state = {"period_id": "Q1", "period_seconds_remaining": 900, "regulation_seconds_remaining": 3600,
             "possession": teams[1], "down": 1, "ydstogo": 10, "yardline_100": 75,
             "score": dict.fromkeys(teams, 0)}
    events = []
    possession_index = 0
    went_ot = False
    reason = "final_max_steps"
    final = False
    limit = integer(spec.get("max_steps", 1000), "max_steps", 1)
    periods = []

    def clock():
        q = int(state["period_id"][1:]) if state["period_id"].startswith("Q") else 5
        state["regulation_seconds_remaining"] = (4-q)*900 + state["period_seconds_remaining"] if q <= 4 else 0

    def emit(kind, pre, *, t=None, players=None, trace=None, terminal=None, assignments=None, cause=None, adjustments=None, outcome=None, boundary=None):
        seq = len(events)
        elapsed = pre["period_seconds_remaining"] - state["period_seconds_remaining"]
        events.append({"event_id": f"{trial_id}/event/{seq}", "event_seq": seq,
                       "possession_id": f"{trial_id}/possession/{possession_index}",
                       "type": kind, "period_id": pre["period_id"],
                       "boundary": boundary,
                       "period_kind": "REG" if pre["period_id"].startswith("Q") else "OT",
                       "pre_period_seconds_remaining": pre["period_seconds_remaining"],
                       "post_period_seconds_remaining": state["period_seconds_remaining"],
                       "elapsed_clock_seconds": elapsed, "unattributed_clock_seconds": 0,
                       "pre_possession": pre["possession"], "post_possession": state["possession"],
                       "pre_state": pre, "post_state": deepcopy(state), "acting_team_id": pre["possession"],
                       "terminal_category": terminal, "assignments": assignments or {},
                       "stat_ledger": "TRY" if kind == "try" else "SPECIAL_TEAMS" if terminal in {"punt", "field_goal"} else "OFFENSE" if kind == "snap" else "TRANSITION",
                       "field_advance_yards": (t or {}).get(pre["possession"], {}).get("field_advance_yards", 0),
                       "orthogonal_flags": {"penalty": "UNSUPPORTED" if (outcome or {}).get("penalty") else False,
                                            "nullified": terminal == "no_play", "interception": bool(trace and trace[2]["outcome"] == "INTERCEPTION"),
                                            "fumble_lost": bool((outcome or {}).get("fumble_lost", False)),
                                            "lateral": bool((outcome or {}).get("receiving_credits")),
                                            "stat_eligible": terminal != "no_play", "rush_design": (outcome or {}).get("rush_design")},
                       "team_credits": t or {}, "player_credits": list((players or {}).values()),
                       "generation_trace": trace or [], "score_delta": {team: state["score"][team] - pre["score"][team] for team in teams},
                       "possession_end_cause": cause, "credit_adjustments": adjustments or [],
                       "feature_availability": deepcopy(features), "flags": ["MODELED"],
                       "provenance_refs": model.model["provenance_refs"]})

    def transition(receiving, cause, *, kickoff=False):
        nonlocal possession_index
        pre = deepcopy(state)
        state["possession"] = receiving
        state["yardline_100"] = 75 if kickoff else max(1, min(99, 100 - state["yardline_100"]))
        state["down"], state["ydstogo"] = 1, min(10, state["yardline_100"])
        emit("possession_transition", pre, cause=cause)
        possession_index += 1

    emit("period_start", deepcopy(state), boundary={"from_period_id": None, "to_period_id": "Q1", "cause": "opening", "reset_clock_seconds": 900})
    periods.append("Q1")
    steps = 0
    while not final and steps < limit:
        if state["period_seconds_remaining"] == 0:
            old = state["period_id"]
            if old == "Q4" and state["score"][teams[0]] != state["score"][teams[1]] or old == "OT1":
                reason = "regulation_complete" if old == "Q4" else "ot_expiration_tie"
                emit("final", deepcopy(state), cause=reason)
                final = True
                break
            if old == "Q2":
                transition(teams[0], "halftime", kickoff=True)
            if old == "Q4":
                transition(teams[1], "ot_reset", kickoff=True)
                new, length = "OT1", 600
                went_ot = True
            else:
                new, length = f"Q{int(old[1:]) + 1}", 900
            state["period_id"] = new
            state["period_seconds_remaining"] = length
            clock()
            emit("period_start", deepcopy(state), boundary={"from_period_id": old, "to_period_id": new,
                 "cause": "halftime" if old == "Q2" else "ot_reset" if old == "Q4" else "quarter_end",
                 "reset_clock_seconds": length})
            periods.append(new)
            continue
        steps += 1
        pre = deepcopy(state)
        op = model.opportunity(deepcopy(state))
        catch, outcome = model.outcome(op)  # allocations and counts already exist here
        if outcome.get("penalty") or outcome.get("untimed_down") or outcome.get("defensive_return_yards"):
            raise ValueError("UNSUPPORTED penalty/untimed/return profile; no invented credits")
        terminal, team = op["terminal"], op["team"]

def _write_once(path, data):
    path.parent.mkdir(parents=True, exist_ok=True)
    try:
        with path.open("xb") as stream:
            stream.write(data)
    except FileExistsError:
        if path.read_bytes() != data:
            raise ValueError(f"immutable artifact conflict: {path.name}")

def zeros(keys):

def allocate(terminal, team, *, passer=None, receiver=None, runner=None):
    """Allocate official attempts/opportunities. Called BEFORE any outcome/yard RNG."""
    if terminal not in TERMINALS:
        raise ValueError(f"UNSUPPORTED terminal {terminal}")
    t = zeros(TEAM_STATS)
    players = {}

    def credit(identity, stat, value):
        if identity is None or identity.get("player_id") is None:
            residual = "sacks" if stat == "sacks_taken" else stat
            t["unassigned_" + residual] += value
        else:
            key = (identity["player_id_namespace"], identity["player_id"])
            p = players.setdefault(key, {"team_id": team, **identity, "stats": zeros(PLAYER_STATS)})
            p["stats"][stat] += value

    if terminal in TARGETED | UNTARGETED | {"sack", "scramble", "aborted_dropback_no_attempt"}:
        if terminal != "non_dropback_targeted_pass":
            t["dropbacks"] += 1
    if terminal in TARGETED | UNTARGETED:
        t["pass_attempts"] += 1
        t["non_dropback_pass_attempts" if terminal == "non_dropback_targeted_pass" else "dropback_pass_attempts"] += 1
        credit(passer, "pass_attempts", 1)
    if terminal in TARGETED:
        t["eligible_target_attempts"] += 1
        credit(receiver, "targets", 1)
    elif terminal in UNTARGETED:
        t[{"throwaway": "throwaways", "spike": "spikes", "other_untargeted_attempt": "other_untargeted_attempts"}[terminal]] += 1
    elif terminal == "sack":
        t["sacks"] += 1
        credit(passer, "sacks_taken", 1)
    elif terminal == "aborted_dropback_no_attempt":
        t["aborted_dropbacks_no_attempt"] += 1
    if terminal in RUSHES:
        t["rush_attempts"] += 1
        t[{"designed_rush": "designed_rushes", "scramble": "scrambles", "kneel": "kneels",
           "credited_aborted_rush": "credited_aborted_rushes"}[terminal]] += 1
        credit(runner, "carries", 1)
    return t, players, credit


def sum_stats(rows, keys):
    result = zeros(keys)
    for row in rows:
        for stat in keys:
            result[stat] += row[stat]
    return result


def derive_tables(events, game, roster, periods, complete=True):
    teams = (game["home_team_id"], game["away_team_id"])

        for row in event["player_credits"]:

    def period_status(p):
        return "KNOWN" if complete or p != periods[-1] else "INCOMPLETE"
    def row_provenance(t, p):
        return {"derivation": "EVENT_LEDGER_SUM_V1", "event_ids": [e["event_id"] for e in events
                 if e["period_id"] == p and t in e["team_credits"]], "roster_ref": "registry"}
    team_rows = [{"team_id": t, "period_id": p, "stat_status": period_status(p), "stats": stats,
                  "provenance": row_provenance(t, p)} for (t, p), stats in team.items()]
    player_rows = [{"team_id": t, "player_id_namespace": ns, "player_id": pid, "period_id": p,
                    "stat_status": period_status(p), "stats": stats, "provenance": row_provenance(t, p)}
                   for (t, ns, pid, p), stats in player.items()]
    scopes = {"H1": ["Q1", "Q2"], "H2": ["Q3", "Q4"], "REG": ["Q1", "Q2", "Q3", "Q4"],
              "OT": [p for p in periods if p.startswith("OT")], "FG": periods}
    team_agg, player_agg = [], []
    # An unplayed future regulation period must never be interpreted as a known zero.
    for scope, primitive in scopes.items():
        known = (all(p in periods for p in primitive)
                 and (complete or periods[-1] not in primitive)
                 and (scope not in {"FG", "OT"} or complete))
        for t in teams:
            team_agg.append({"team_id": t, "period_id": scope, "status": "KNOWN" if known else "INCOMPLETE",

                               "provenance": {"derivation": "PRIMITIVE_PERIOD_SUM_V1", "period_ids": primitive},
                               "stats": sum_stats([player[(*key, p)] for p in primitive], PLAYER_STATS) if known else None})
    scores = {}
    for scope in scopes:
        rows = [r for r in team_agg if r["period_id"] == scope]
        scores[scope] = ({"total": sum(r["stats"]["points"] for r in rows),
                          "home_margin": rows[0]["stats"]["points"] - rows[1]["stats"]["points"]}
                         if all(r["stats"] is not None for r in rows) else None)
    return team_rows, player_rows, {"team": team_agg, "player": player_agg, "scores": scores}

def finalize_validation(trial):
    trial["validation"] = validate_trial(trial)
    if trial["validation"]["status"] != "PASS":
        trial["status"]["state"] = "INVALID"
    residuals = any(any(row.get("stats", {}).get("unassigned_" + k, 0) != 0 for k in RESIDUALS)
                    for row in trial.get("team_periods", []))
    reasons = []
    if trial["status"]["state"] != "COMPLETE":
        reasons.append("TRIAL_" + trial["status"]["state"])
    if residuals:
        reasons.append("PLAYER_ID_UNRESOLVED")
    if "SCENARIO_ONLY" in trial["flags"]:
        reasons.append("SCENARIO_ONLY")
    trial["status"]["adapter_projection_allowed"] = not reasons
    trial["status"]["projection_blockers"] = reasons
    return trial

        catch, outcome = original(self, op)
        op["team_credits"]["dropbacks"] += 1
        return catch, outcome

    result = simulate_joint_games(spec, input_root=root, inputs=inputs, n=2, seed=1, output_root=tmp_path / "out")

    assert len((Path(result["artifact_directory"]) / "trials.jsonl").read_text().splitlines()) == 2
