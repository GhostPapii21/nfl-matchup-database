# data/historical — box backfill MANIFEST

**Built:** 2026-11-11 ~10:40 AM ET by Blitz (NFL Research) from the shared Grok box, at the user's (Rico's) request to move historical data and pregame projections into GitHub.

**Research only.** Nothing here is a pick, slip, or bet. Projection CSVs had lean/edge/price columns stripped. This PR does not touch `projection_ready`, model weights, formulas, or `core/`. NFL-49 and NFL-56 gates are unchanged.

**Status key:** `verified` = pulled from a named source and checked against it or reconciled. `inferred` = derived or estimated (for example tackler/PBU tags, not charted coverage). `unverified` = model output or unaudited. **Pull time** = file time on the box (ET). Many files were copied onto the box on 2026-11-06 around 7:28 AM ET, so for those the pull time is a lower bound. Prefer timestamps in filenames or READMEs.

**Dedupe:** every file was git-blob-hashed and skipped if the identical blob already exists on `main` or any branch of this repo (as of 2026-11-11 10:20 AM ET). Files over 10 MB were gzipped (text) and none is over 50 MB.
