## 1. What is implemented on the opt-in path (and how)

| Semantics | Mode | Source | Rule implemented |
|---|---|---|---|
| Penalties (scrimmage) | `canonical_log_v1` | PEN; weeks strictly before target **that exist in PEN** | Per-snap foul probability = offense's accepted offensive fouls/snap + defense's accepted defensive fouls/snap. Yards, no-play, auto-first-down resampled from that team-side's own accepted fouls. Half-distance rule. No-play fouls replay the down; live-ball fouls are enforced after the play and **dropped if the play changed possession or scored**. Defensive no-play foul as time expires -> one untimed down. Never scores, never changes possession. Games are filtered by season (PEN has no season column, so only game_ids present in the season-filtered log are kept). |
| Penalty weeks missing from PEN | — | PEN | As-of W10 the model uses W1-8; **W9 penalty data is unknown** (`unknown_weeks: [9]` in sim meta). It is not treated as zero penalties; rates are per snap over the weeks that exist. |
| Kick / punt return TDs | `asof_league_v1` | PBP9, league, weeks < target | Kick-return TD and punt-return TD at the as-of league rate (PBP9 W1-9: 1 of 1,404 kickoffs, 1 of 1,033 punts). Field position after returns still comes from the empirical first-scrimmage spot (kickoffs) and punt **net** (punts). |
| Defensive returns | `asof_league_v1` | PBP9, **all 32 teams**, weeks < target | **Changed (review D2).** On a simulated interception or fumble lost, `(return_yards, return_touchdown)` is drawn from the league pool of the same turnover kind (PBP9 W1-9: 197 INTs with 9 return TDs, mean return 11.5 yds; 157 fumbles lost with 6 return TDs, mean 1.6 yds). The old code read these from the sampled NYG/WAS row, whose 16 W1-9 turnover rows had 0 return TDs (Ghost6 review), so it never scored one (TNF lock: `def_td` 0.0 over 100k). A return TD (or a return reaching the goal line) scores 6 + try for the defense. End-zone turnovers without a return TD are touchbacks (ball at the 20). |
| Overtime | `official_2025_regular_season` | NFL rule (2025 regular season) | 10-minute period, coin-toss receiver, both teams guaranteed a possession, then sudden death. Defensive score on the opening possession ends it. Clock expiry = tie. |

Punt net remains a separate PBP field-position quantity (`_punt_net_from_row`). Punt return yards are implied
(`kick_distance - net`) and never added a second time; a punt-return TD is a separate event.

## 2. Still UNSUPPORTED (rejected, not invented)

* Kick-play fouls (kickoff/punt/FG/try rows): excluded from the foul model. Exposure (PEN, W1-8): 224 of 1,736 accepted
  flags (12.9%), 1,921 of 14,068 yards (13.7%). Their field-position effect is partly inside the empirical kickoff start
  spots and punt nets already. A test checks the filter on a synthetic log.
* Declined / offsetting fouls (PEN: 249 rows): no effect by definition; not simulated.
* Blocked punts/FGs, onside kicks, fake punts, 2-point tries after penalties: not modeled.
* Penalty-specific clock rules (10-second runoff, clock start/stop): a flat 4 s per no-play.
* Joint producer (player opportunity path): still raises UNSUPPORTED on penalties/return yards.
* Team-specific return-TD rates: league rate only (team samples are 0-1 events).

## 5. The level gap is a model problem, not a semantics problem (corrected, review D7)

The locked TNF sim has WAS 22.1 / NYG 12.6, P(NYG win) 0.21, vs a market near 0.55 and 40.5-41 total (market figures:
Ghost6's sanity note in `docs/ACCEPTANCE_STATUS.md` d65ad98; CBS/DraftKings -2.5 / 40.5 at 9:49 AM ET per the Betting Hub
thread). v1 blamed "team-only empirical bootstrap, no QB/injury adjustment". That was **wrong as the main cause**:

* **Main cause: head-to-head-only defense conditioning.** `simulate.py` always enables `_defense_cond`, the config's
  `defense_interaction.mode` is `h2h_only`, and `sample_snap` draws every snap from the (offense, defense) pool when it has
  at least 5 plays. For WAS@NYG that pool is one game, W5 `2026_05_NYG_WAS` (27-27). Ghost6's instrumented run (seed 777,
  n = 2,000) found 100% of snaps tagged `DEF_COND`; SENS shows about 113 `DEF_COND` snap flags per simulated game with
  it on and 0 with it off.
* **With it off (diagnostic only, engine default unchanged):** NYG 15.68 / WAS 17.48, P(NYG win) 0.439 at n = 6,000 (SENS);
  Ghost6 got NYG 16.15 / WAS 17.50, 0.45 at n = 2,000. That closes most of the win-probability gap.
* **The total stays low (about 33.2 vs 40.5)** with it off, so a second level problem remains (candidates: pace, no
  QB/injury adjustment, coarse cells). Not isolated. Logged under NFL-49; nothing tuned here.

**Every 100k lock made so far (TNF 2026_10_WAS_NYG 20261112T171258Z, BUF@NYJ 20261112T172055Z, and the uncommitted
CAR@NO run) ran under unreviewed bounds with h2h conditioning on: known model error, not an edge.** `rocket` R5 flags
them `KNOWN_MODEL_ERROR_UNREVIEWED_BOUNDS`.
